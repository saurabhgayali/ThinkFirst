⚡ Quick Start

ThinkFirst is a single file. To get started, copy SKILL.md and paste it into your AI system's custom instructions or system prompt.

Download SKILL.md View Full Guide
✓ That's it! You now have complete ThinkFirst behavior. No installation, no dependencies, no additional files needed.

For platform-specific guidance, see the installation methods below.

✨ What You Get

8 Assistance Modes

BYPASS (emergency), GOOGLE (trivial lookup), TRY_FIRST (learn), TEACH (concepts), GUIDE (methodology), REVIEW (feedback), DELEGATE (automation), ASSIST (full help)

Per-Request Decision Logic

Evaluates 12 criteria before every response to determine the best assistance mode for the user's situation.

Effort Assessment Format

Optional structured effort assessments to help users understand complexity without token counting.

Tone Guidelines

Firm, honest, practical, encouraging — designed to feel like a mentor, not a vending machine.

Completely Self-Contained

No external dependencies. SKILL.md is the complete specification. All behavioral rules included.

Model-Agnostic

Works with ChatGPT, Claude, Gemini, local models, and any AI system accepting custom instructions.

📦 Installation Methods

🔵 OpenAI ChatGPT

Use ThinkFirst in ChatGPT's web UI or API

1
Web UI: Open ChatGPT, go to Settings → Customize ChatGPT → "Custom instructions"
2
Paste the contents of SKILL.md
3
API users: Use SKILL.md as the system role
✓ Easiest
🤖 Anthropic Claude

Use ThinkFirst in Claude.ai or API

1
Web UI: Start a new conversation at claude.ai
2
Paste SKILL.md content as your first message
3
Projects: Create a project and add SKILL.md as system prompt
4
API: Use SKILL.md as system role
✓ Easiest
✨ Google Gemini

Use ThinkFirst in Gemini's web interface

1
Go to gemini.google.com
2
Start a new conversation
3
Paste SKILL.md content at the start
✓ Easiest
💻 Claude CLI

Use ThinkFirst with Claude command-line tool

1
Install Claude CLI: npm install -g @anthropic-ai/claude-cli
2
Create a config file or prefix SKILL.md to your conversation
3

cat SKILL.md > context.txt cat context.txt your-question.txt | claude

📝 VSCode (GitHub Copilot)

Use ThinkFirst in VSCode with Copilot

2
Copy the contents of SKILL.md into it

🚀 Automated Setup (All Platforms)

Single command to download, extract, and deploy ThinkFirst

1
Linux / macOS:
bash -c "$(curl -fsSL https://raw.githubusercontent.com/saurabhgayali/ThinkFirst/main/deploy.sh)"
2
Windows (PowerShell):
powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/saurabhgayali/ThinkFirst/main/deploy.ps1' -OutFile deploy.ps1; .\deploy.ps1"
3
What it does: Downloads the latest release, extracts all files (SKILL.md, rules/, examples/, tests/), and copies them to your current directory. A comparison is performed to avoid overwriting existing files.
4
Optional: Specify a target directory: TARGET_DIR=/path/to/folder bash deploy.sh (Linux/Mac) or $env:TARGET_DIR='C:\path'; .\deploy.ps1 (Windows)
✓ Automatic

❓ FAQ

Do I need to clone the entire repository?

No. You only need SKILL.md. The repository includes supporting documentation (rules/, examples/, tests/) for developers and contributors, but they're not required at runtime.

Which AI system should I use?

ThinkFirst works with any AI system. Popular choices are ChatGPT, Claude, or Gemini. For developers, local models (Ollama, LM Studio) also work well.

Can I modify SKILL.md?

Yes. SKILL.md is designed to be customizable. Feel free to adapt it to your preferences or organizational style.

Does ThinkFirst work offline?

Yes, if your AI system can work offline. ThinkFirst is pure text — no cloud dependencies.

How do I contribute?

Contributions are welcome! See README.md for guidelines. For issues or suggestions, open an issue on GitHub.

What is the license?

MIT License. You're free to use, modify, and distribute ThinkFirst. See LICENSE for details.
